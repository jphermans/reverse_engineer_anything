Werkruimte-root
Map waarin analyse-werkruimtes worden aangemaakt (leanrea-regel: werk altijd op een kopie). Standaard: /a0/usr/workdir/rea. Bij een aangepast pad maakt de plugin de map automatisch aan bij gebruik; bij verwijderen van de plugin blijft deze map bewust bestaan (gebruikersdata).
Historiek-limiet
Maximale aantal bewaarde historieke-regels (10–2000, standaard 200).
